# Micrograd

Micrograd is a minimal automatic differentiation (autograd) engine created by **Andrej Karpathy**. It demonstrates how neural networks and backpropagation work under the hood by implementing a small computation graph from scratch in Python.

## What I'll Learn

- The `Value` class
- Operator overloading (`+`, `*`, etc.)
- Computation graphs
- Automatic differentiation
- Backpropagation
- Building and training a simple neural network
